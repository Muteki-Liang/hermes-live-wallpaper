#🎬 Hermes 背景视频插件 · Ver.1.3

为 Hermes 桌面客户端添加**全屏循环背景视频**——视频以 20% 可见度铺满界面背景，不影响 UI 可读性；左右侧栏自动半透明透出视频；带完整图形化设置页。

> BETA 版新增：**视频内容在窗口内自由移动**（0%~100%，无黑边）——像壁纸的"填充方式"一样调整画面位置，窗口始终全屏。
> 1.2版本新增：提高了兼容性，增加了右上角调试徽标隐藏功能
> 1.3版本新增：现在可以替换照片了，支持jpg和png格式

- 🖼 **视频内容水平位置可调**（0% 靠左 / 50% 居中 / 100% 靠右）
- ⚙️ **提供图形化设置页**（侧边栏「背景视频」入口，或 `Ctrl+K` 搜"背景视频"）：

## 📦 安装

1. 关闭 Hermes 桌面客户端
2. 将 `bg-video` 文件夹整个复制到：
   ```
   %LOCALAPPDATA%\hermes\desktop-plugins\
   ```
   最终路径：
   ```
   %LOCALAPPDATA%\hermes\desktop-plugins\bg-video\plugin.js
   ```
3. 重新打开 Hermes 桌面客户端
4. 左侧边栏出现「背景视频」入口 → 点击打开设置页

> 若入口未出现：`Ctrl+K` → 输入 `Reload desktop plugins` → 回车

## 🔧 使用

- **开箱即用**：插件内置 `bg-default.mp4`（绝区零 2.6 爱芮），无需任何配置
- **换自己的视频**：设置页 → 视频文件路径 → 填本地视频绝对路径 → 保存并应用
- **恢复默认**：清空路径输入框 → 保存（自动回退到自带视频）
- **调整画面位置**：设置页 → 视频水平位置 → 拖动滑块实时预览

## 🗑 卸载

删除 `%LOCALAPPDATA%\hermes\desktop-plugins\bg-video\` 文件夹即可，无任何残留。

## 📋 兼容性

- 平台：Windows 优先（macOS/Linux 理论上可用，未完整测试）
- 客户端：Hermes Desktop v0.20.x
- 视频格式：MP4 / WebM 等浏览器原生支持格式

## ⚠️ BETA 注意事项

- 目前的版本只适配暗色外观模式（界面右上角设置➡️外观➡️主题右侧选择暗色），明亮模式会导致显示有问题
- 视频解码消耗少量 GPU/CPU，低配设备可调低"视频可见度"或关闭
- 侧栏半透明为自动检测实现，个别界面主题下可能有不完美表现，欢迎反馈
- 已知限制：视频自动播放需静音（浏览器策略），背景视频不会带声音
